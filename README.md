# Galaxy’s Edge Ride Planner (C++)

A Star Wars–themed command-line application that helps plan a visit to Disneyland’s Galaxy’s Edge by tracking ride wait times and suggesting the most efficient ride order.

## 🚀 Features
- View available rides
- Calculate total wait time
- Suggest best ride order (shortest wait first)
- Update wait times dynamically

## 🧠 Concepts Used
- Structs
- Vectors
- Sorting algorithms
- User input handling

## 🖥️ Example Output
Millennium Falcon: Smugglers Run – 45 min  
Rise of the Resistance – 75 min  

Suggested order updates based on wait times.

## 🌌 Theme
Inspired by Disneyland’s Galaxy’s Edge and Star Wars attractions.

- Implementing sorting logic
